# Phốcus

An editorial website about Hanoi's urban planning and infrastructure.

## Commands

- `npm run dev` — start the local development server
- `npm run build` — type-check and create a production build
- `npm run lint` — check code quality
- `npm run format` — format the project with Prettier

## Responsive UI requirement

All UI must work without horizontal page scrolling from a 320px viewport through desktop widths. New and modified components must use fluid sizing, protect long content and media from overflow, and be verified at mobile, tablet, and desktop widths.

## UI scalability requirement

Every UI change must work from a 320px viewport through desktop widths. Before considering a UI task complete, verify that content reflows without horizontal scrolling, controls remain usable by touch, images and media stay within their containers, and text remains legible without relying on fixed dimensions.

The complete implementation guidance is in [AGENTS.md](./AGENTS.md).
