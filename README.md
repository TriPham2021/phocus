# Phốcus

Phốcus is a React editorial website about the historical evolution of Hanoi's urban planning and infrastructure.

## Getting started

```bash
npm install
npm run dev
```

The application will start through Vite's local development server.

## Stack

- React + TypeScript
- Vite
- Tailwind CSS
- React Router
- ESLint + Prettier

## Useful commands

```text
npm run dev           Start local development.
npm run build         Type-check and build for production.
npm run lint          Run code-quality checks.
npm run format        Format project files.
```

## Project structure

- `src/pages/` contains route-level pages.
- `src/components/` contains reusable layout, navigation, chapter, and editorial UI.
- `src/data/episodes/` contains chapter metadata and editorial Markdown sources.
- `src/router/` defines application routes.
- `src/index.css` contains global tokens, shared styling, and responsive layout rules.
